# RTB Guide

Authoritative source for the RTB learning and case-preparation website.

## Build approach

- Model the interaction and responsive behaviour on `ronandownes/education`.
- Keep the site directly editable in GitHub / VS Code.
- Use flat rectangular topic panels and several restrained blue shades.
- Use the four-corner-dot motif as the site mark.
- Keep the selected navigation/topic visibly marked while scrolling.
- Keep topic navigation as narrow as practical; long labels wrap rather than forcing a wide column.
- Each topic can expand/collapse.
- Users choose which terms enter the glossary; selections persist in browser local storage.
- Current and historical RTB rules/data must be dated and kept analytically separate.
- Decision-useful RTB tables are rendered directly on the site rather than requiring Excel or Google Sheets.

## Content rule

The public learning site is neutral and educational. Individual tenancy material may be used to decide what tools, checklists and concepts deserve inclusion, but case-specific evidence should not be exposed as general RTB guidance.

The site may support case preparation and non-legal representation services. It must not present the service as legal advice or as a law firm.
